# 本地 MVP 验收映射

2026-10-13，版本 0.1.1。范围为第 5 节已确认最小集，及用户确认的 Cytoscape.js、层级目录、节点下创建。

| 大纲 | 实现入口 / 行为 | 验证与边界 |
|---|---|---|
| 5.1 常用块 | Milkdown 所见即所得；标题、正文、待办、表格、代码、引用；工具栏文件/图片、媒体嵌入 | Markdown 往返、附件保存回读/预览通过；文件以持久化链接插入，点击预览/下载；媒体按需预览，支持 HTTPS 音视频、YouTube/Vimeo，不支持任意 HTML |
| 5.2 自动建图 | 先保存正文，再按已启用配置提取 JSON 实体；精确名称复用隐藏 Concept，写 CHILD_OF；相同正文/模型缓存 | 模拟云协议 + 真实 Kùzu 通过，失败保正文；真实模型待 Key，不声称已验证质量 |
| 5.2 人在回路 | 节点管理添加/修正/移除可见关系；API/MCP 纠正后台关系、合并 Concept | 统一拒绝跨库/环/非法平行；缓存不复活人工移除边；Concept 隐藏，批量自动审核流程待定 |
| 5.2 引用与关联 | 文档底部反向链接、相关文档 | 跨库 Markdown 聚合，改名不失效，不存引用边；共享概念计数推荐，不是语义搜索 |
| 5.3 图谱 | 图谱/目录切换；力导向、拖动、缩放、适应画布、类型/全文/关系筛选 | 真实 API 图数据；圆节点，子→父实线箭头，平行虚线；隐藏 Concept |
| 5.3 查询导出 | 中心节点 1–3 跳；最短路径；当前子图 JSON、PNG | 路径双向探索，返回实际边方向；无路径提示；仅小图性能验收 |
| 5.4 导入 | Markdown 文件/文件夹、CSV、Graph KB JSON | 文件夹映射父节点，相对 .md 链接转稳定 ID；CSV 引号/换行；非法图整批回滚；2000 节点/批，UI 文件总量 24 MiB |
| 5.4 导出 | 全库 JSON、Markdown ZIP（graph.json、正文、附件） | JSON 含隐藏概念/关系/附件，导入重映射 ID，不覆盖已有节点；同批 Markdown 引用相对化，范围外引用保留 node: |
| 5.6 首页 | 卡片计数/更新时间、名称筛选、新建、重命名、确认删除；全局搜索、设置 | 实际读写 Kùzu；空库无更新时间；改名不改 ID |
| 5.6 目录窗口 | 可折叠缩进树、右键节点操作、左右可拖分栏；目录左键右侧编辑，图谱左键开独立窗口 | 多父按已有边投影；保存、关闭、冲突保草稿；原图谱/目录保持可用 |
| 5.7 REST/MCP | 知识库/节点/关系/正文 CRUD、查询、导入导出、回收站、附件、设置共用工具层 | Bearer 鉴权，127.0.0.1 随机端口；MCP stdio 2025-11-25；设置中显示配置，重启需更新；真实子进程调用通过 |
| 5.8 删除恢复 | 节点支持仅删当前/级联删除独占后代，保护外部父节点共享分支；节点/整库进回收站，恢复原 ID、正文和可恢复关系 | 30 天后在启动、每小时及请求维护时清理；关闭期间不唤醒应用；恢复冲突边跳过并提示；附件随节点限制访问/过期清理 |
| 5.8 删除引用 | 灰色“已删除节点”占位，阻止点击 | 渲染装饰，保留正文原链接；窗口聚焦/重载刷新；恢复后可用 |

自动化入口：npm test、npm run test:ui、npm run test:runtime、node scripts/test-installed.mjs。结果与包位置见根目录 PROGRESS.md。

5.5 候选池、Beta、商店发布不属于完成声明。Tag/File/Person/Task 共享文档和图谱能力，未添加大纲未定义的任务状态、人物资料表等工作流。
